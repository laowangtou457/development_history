# 武术指导 · 分镜格数确定性兜底（不足 16 格修复）

日期：2026-09-29
状态：已验证

## 用户反馈

文字分镜提示词只生成了五个分镜，但画面布局是 4×4 十六宫格分镜表。

## 根因

generate 流程对 Step1 招式编排（qwen3:8b）的 moves 只有 `if not moves` 非空校验，**不校验数量**。8b 只输出 5 个招式就直接进入 Step2 组装 → 图片提示词只有 5 格，与 4×4 十六宫格布局矛盾。（已知惯例：8b 强制字段经常不遵守，必须确定性兜底。）

## 修复（backend/app/api/martial_arts.py）

### 1. `_parse_grid_count(grid_val)`
从宫格规格文本解析格数（"16 = 4×4" / "16格" / 16 → 16），默认 16。

### 2. `_evolve_moves(moves, target)`
确定性兜底：招式不足 target 时，用同招的不同攻防角度/双方换位演化补足（变体循环：攻防换位/变换角度/双方换位/反手变式/缠斗变式/节奏变化），保证 build_input 永远有 target 条招式。

### 3. generate 流程
- 解析 N（前端 grid 或 card.grid）
- `moves = _evolve_moves(moves, grid_n)`，补足时更新监控阶段"已从 X 招补足到 16 招"
- build_input 明确标注"【招式列表】（共 16 招，与宫格总数一致）"+"图片提示词必须逐招写满全部 16 格，禁止少于 16 格"
