# 武术指导 · 视频动作动态表现强化（提示词层）

日期：2026-09-28
状态：已验证

## 需求

历史任务生成的视频动作过于呆板，没有体现武指 skill 的意义（武打节奏/发力/连招/张弛）。从提示词层强化。

## 强化点（backend/app/api/martial_arts.py）

### 1. Step1 招式编排（PLAN_SYSTEM）
- **动态动词(强制)**：每招 point 必须含至少 1 个强动态动词（冲/推/撩/扫/砸/卸/震/勾/崩/截/缠/绞）+ 发力轨迹（"自腰间直线崩出""借转身旋劲横扫"）
- **速度标记(强制)**：每招 point 末尾标【快/中/慢/骤停】，至少 4 处【快】、2 处【骤停】，招式有快慢张弛

### 2. Step2 提示词组装（BUILD_SYSTEM）
**视频提示词规范强化**：
- [分镜执行清单]：每格动作要点改为"起势→发力→收势三拍" + 速度标记 + 镜头标签
- 新增 **[动作动态表现](强制)** 段：全片禁止"原地摆 pose"；每镜头"蓄力→爆发→收势"或连续位移三拍动作流；速度标记有张弛不匀速；≥2 处连招链（2 招以上无缝衔接不切镜）；≥3 处决定性瞬间（击中/化解/失衡）配推近/跟拍；肢体末梢有位移弧线与速度线
- [动作连贯] 强化：≥2 处连招链 + 1 处极限状态；惯性/重心转移/落地震尘必须可见
- 字数上限 600-800 → 700-1000

**图片提示词规范强化**（分镜图源头，H3 参考图也应有张弛）：
- **速度张弛(强制)**：每格动作要点末尾标【快/中/慢/骤停】，至少 4 处【快】、2 处【骤停】
- **招式不重复(强制)**：16 格按招式列表逐招写入，禁止重复招式凑格；不足 16 格用"同招不同攻防角度/双方换位"演化

## 验证（真实端到端，太极宗师对外家拳师）

**视频提示词（1261 字）**：逐格清单每格含 动作要点 + 【快/中/慢】 + 镜头标签（如
`第2格｜拳师直冲｜外家拳师猛然向前冲，右拳自腰间直线崩出，直取太极宗师胸口｜[快]｜[中景]`）；
节奏张弛：02/03/05/06/08【快】↔ 01/16【慢】↔ 04/07【中】；末尾[动作风格]段（一代宗师+叶问美学）。

**图片提示词（1071 字）**：每格动作 + 【快/慢/中】 + [姿态]，动态动词（崩出/横扫/缠丝/突袭/挣脱/卸力）明显。

**已知限制（如实说明）**：
- 8b 在 16 格填充时仍会出现招式近似重复（如 12/13 近似 06/07）——模型能力上限，提示词已要求不重复但无法完全杜绝
- 真正生成动态视频的是 H3（qwen3vl-32B int8 + ref2va），提示词是"指挥棒"，模型动态能力决定最终上限；若仍偏呆板，建议试 6-8s 更长时长（连贯性更好）或 first_last 首尾帧模式

## 使用

无需前端改动。重新「生成武打分镜提示词」→ 分镜图 → 视频，新提示词自动生效（旧历史记录保持旧提示词）。
