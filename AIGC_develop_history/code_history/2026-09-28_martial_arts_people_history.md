状态：已验证

## 一、需求

1. 历史任务面板：历史任务**产物**（角色图/分镜图/视频）都要显示；任务**开始时间**和**完成时间**都要表现出来。
2. 人物数量一致：用【太极宗师对外家拳师，晨曦庭院，要有太极哲学】生成的视频/分镜图只有太极宗师一人，外家拳师没体现。要求图片和视频必须与需求的人物数量一致。

## 二、实现

### 1. 历史面板增强（前端 index.tsx）

历史列表每项：
- 需求 + 开始时间（createdAt）+ 完成时间（updatedAt，未生成完显示开始时间）
- **三产物缩略图横排**：角色形象图 / 分镜图（img）+ 武打视频（video muted preload="metadata" 显示首帧）；未生成的产物显示虚线占位框
- 点击条目恢复工作区（原有行为）；删除按钮保留

### 2. 人物数量一致性（后端 martial_arts.py）

**PLAN_SYSTEM（招式编排）新增强制规则**：
- 人物清点：识别需求全部人物逐一列入 `card.characters`，数量与需求严格一致（"太极宗师对外家拳师"=2人），禁止漏人、禁止对手虚化为剪影
- 姓名原称：`characters[].name` 必须用需求原称（如"太极宗师""外家拳师"），禁止用"主角/对手"标签充当姓名；`role` 才填主角|对手|配角
- 输出格式示例更新为双角色示例
- 招式 point 必须含双方姓名+相对方位（如"宗师向右转身，拳师自左侧直拳逼近"）

**BUILD_SYSTEM（提示词组装）新增约束**：
- 图片提示词：开头即写"画面共N人：A（特征）、B（特征）"，每个出场人物独立角色块，对手具体呈现不缺席
- 视频提示词：新增 [人物数量一致] 段——出场人物数量与参考图/需求一致，双方全程同框对垒，对手不可虚化

**_card_markdown 新增「出场人物」行**：`| 出场人物 | 太极宗师（主角）、外家拳师（对手） |`，随锚定卡进角色图 prompt。

**前端角色图 prompt 强化**：明确"画面必须包含需求中的全部出场人物（人物数量与需求一致，主次分明，多人同框对垒站位）"。

### 3. 附带修复：`_extract_two_sections` 健壮化

真实生成暴露 bug：LLM 有时不输出「===图片提示词===」标题（直接进正文），旧解析只有"双标题"分支 → 图片段整个丢进 img、**视频段被丢弃为空**（videoPrompt=0）。重写为四种布局兼容：双标题 / 仅视频标题 / 仅图片标题 / 无标题。单元测试 4 例全 PASS。

### 3b. 二次修复（v3，用户复报「视频提示词被合并进文字分镜提示词」）

用户复报后真实生成仍 videoPrompt=0。检查真实 raw 发现：LLM 这次输出**裸 `===` 分隔线**（仅 3 个等号、无「视频提示词」标题），
旧正则 `===+\s*标题\s*===+` 要求标题两侧都有等号 → 裸 `===` 不匹配 → 整段被当图片段、视频段丢失（界面表现：文字分镜提示词很长、视频提示词区块消失 → 点视频报「请先生成武打分镜提示词」）。

v3 重写为「第一个分隔线分段 + 标题感知」：
- 正则改为 `={3,}\s*标题?\s*(?:={3,})?`（3+ 等号即可，标题可选，尾等号可选）
- 第一个分隔线带「图片提示词」标题 → 图片段=其后到下一分隔线，视频段=下一分隔线之后
- 否则（裸 === 或「视频提示词」标题）→ 图片段=分隔线之前，视频段=之后（剔除后续多余分隔线）
- 完全无分隔线 → 整段图片

验证：单测 6 例 PASS（含真实裸分隔线用例）；**真实 generate 复测通过**（imagePrompt=1215 / videoPrompt=526，videoPrompt 完整含参考图阅读协议+人物数量一致+分镜执行清单）——吸取上次"单测过但真实失败"教训，本次以真实生成为准。
