# 武术指导 · 多角色定义（锚定卡多人物）

日期：2026-09-29
状态：已验证

## 用户反馈

人物锚定卡只记录了一个角色，多角色时会导致另一个角色形象不稳定。生成武打分镜提示词的步骤增加按钮可以添加新角色定义，在人物锚定卡中体现多人物定义。

## 根因

1. **前端只有"人物/体型气质"一个输入框**——用户只能描述主角，对手角色全靠 8b 从需求文本猜，形象不稳定。
2. **锚定卡只展示"出场人物：A（主角）、B（对手）"名字行**——每个角色的性别/年龄/体型/服装/武器长短没有完整落进卡，图片提示词组装时对手角色块信息不足。
3. **8b 常漏输出 card.characters 数组**（退化）——即使需求里明确两个角色，锚定卡也可能没有角色定义。

## 修复

### 前端（MartialArts/index.tsx + martialArts.ts）
- 新增 `MartialCharacterDef` 类型 + `characters` state（默认 1 个主角卡片）
- 高级选项"人物/体型气质"下方新增「角色定义（多角色）」区块：
  - 每个角色卡片：角色名 / 身份（主角|对手|配角）/ 性别 / 年龄 / 体型与气质 / 服装 / 兵器 / 武术体系
  - 「添加新角色」按钮（+）/ 「移除」按钮（角色数 >1 时）
- 提交时过滤空角色，`characters` 数组随 generate 传给后端

### 后端（martial_arts.py）
- `MartialArtsRequest.characters: Optional[list]` 新字段
- `_build_user_message`：拼【用户指定角色】(强制：人物清点以此为准，characters 数量必须与此完全一致、逐一对应) 段
- `_card_markdown`：新增「角色定义」行，每个角色完整输出：①角色名（身份）性别：X、年龄：X、体型气质：X、服装：X、武器：X、武术体系：X（序号①②③…）
- **`_merge_characters` 确定性兜底**：用户传了 characters 时强制合并进 `card.characters`（用户定义优先，缺省字段从 8b 同名角色补齐）——不依赖 8b 是否输出 characters，保证锚定卡必含全部角色定义

## 验证

- tsc --noEmit 通过
- 真实调用（太极宗师 vs 外家拳师，双角色完整定义）：
  - 锚定卡含「出场人物：太极宗师（主角）、外家拳师（对手）」
  - 「角色定义」行含双角色全字段（性别/年龄/体型/服装/武器/武术）✅
  - 顶层字段使用用户定义（白色绸缎长袍/黑色短打劲装等）✅
- 后端重启 PID 44668

## 使用

高级选项 → 角色定义（多角色）→ 默认主角卡片，点「添加新角色」增加对手/配角 → 填形象 → 生成武打分镜提示词。锚定卡「角色定义」行即体现全部角色。
