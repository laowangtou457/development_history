# 武术指导 · 角色形象图结构化重组（场景融合 + 具体动作 + 防虚空）

日期：2026-09-29
状态：已验证（真实生成目检）

## 用户反馈

生成的角色形象图仍有：场景结构分离、人物动作僵硬不成武术动作、人物占位脱离场景站在虚空处。

## 根因

1. 角色图 prompt 是"锚定卡全文 + 一段笼统动作描述"的平铺结构，模型抓不住"人物在场景中"的空间关系 → 人物与背景分离成两层
2. 动作只有抽象参考（"黄飞鸿式沉桥架式"），Flux2-4B 无法翻译成具体姿态 → 僵直站桩
3. 无"踩地/接触场景元素"约束 → 人物飘在虚空

## 修复

### 1. 前端模板结构化重组（MartialArts/index.tsx）
- 新增 `cardField(card, label)`：从锚定卡提取指定项目（场景天气氛围/场景/场景布置与构图/武打姿态参考）
- handleGenerateCharacter 的 prompt 改为四段式：
  - **【场景】**：场景天气+场景+构图（含人物站位），强制"双脚踩实地面/桥板/台阶，站立于场景纵深，与场景元素产生明确接触，禁止脱离/悬浮/分离成两层"
  - **【人物】**：锚定卡全文（性别/年龄/服装/武器/体型）+ 人物数量一致
  - **【动作】**：姿态参考 + **具体化为可见武术姿态**（前弓步/沉马半蹲/重心下沉/护胸/掌前探/身体微侧/发力肌群可见/非站桩/衣袂带风）
  - **【整体】**：同一光感同一透视、景深合理、禁拼贴感

### 2. 后端确定性兜底（generate-image）
prompt 不含"踩实/虚空/脱离/漂浮/深度融合"任一关键词时，自动追加[画面结构硬约束]段（人物与场景深度融合、双脚踩实、全身入画、禁止分离/虚空/僵直站桩）——不依赖前端与 LLM 自觉。
