# 武术指导 · 生图提示词自动英文化（qwen3:8b 翻译）

日期：2026-09-29
状态：已验证（真实生成目检）

## 用户诉求

人物锚定卡是否也改为英文，模型更容易理解？

## 分析结论

锚定卡是中间产物，三个消费方要求不同：
- 前端展示（用户要读）→ 中文
- Step2 组装（qwen3:8b，中文理解强）→ 中文更稳
- **生图模型（Flux2-Klein-4B / qwen3_4b CLIP）** → 英文提示词执行更稳定（细节歧义少、姿态/材质/构图执行更准）

真正喂模型的图片提示词英文化收益最大，卡本身全英文反而牺牲用户可读性与 8b 组装稳定性。因此：**锚定卡保持中文，生图提示词后端自动英文化**。

## 实现（backend/app/api/martial_arts.py）

### IMAGE_PROMPT_TRANSLATE_SYSTEM + `_translate_image_prompt(prompt)`
- 直连 Ollama qwen3:8b（无图 /api/chat，temperature=0.2，keep_alive:0 自动卸载，gpu_serial 串行）
- 规则：忠实翻译全部细节（人物数量/性别/年龄/服装材质颜色款式/武器长短/场景布置构图/天气光感/具体武术姿态/防虚空约束），保留段落结构（【场景】【人物】【动作】【整体】→ [Scene][Characters][Action][Overall]）
- 仅含中文时触发；翻译失败/超时/结果异常（<60 字或无英文）→ **回退中文**，不阻断生图

### generate-image 接入
组装完（含手动附加约束）后调用翻译 → Flux2-4B。
