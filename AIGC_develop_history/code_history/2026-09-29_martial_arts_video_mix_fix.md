# 武术指导 · 视频提示词混入文字分镜提示词（解析鲁棒化修复）

日期：2026-09-29
状态：已验证

## 用户反馈

视频提示词又出现在文字分镜提示词里，为什么这么不稳定。

## 根因（两层）

1. **解析器只认 `=` 分隔线**：BUILD 输出协议要求两段用独立一行 `===` 分隔。但 8b 对协议遵守不稳定——本次输出用了 `---` + `**视频提示词**` 标题，旧 `_extract_two_sections` 的 `sep_re = ={3,}` 完全不匹配 → 找不到分隔 → **整段 raw（含视频内容）全当图片段**，视频提示词就"混进了"文字分镜提示词。查 8 条历史记录，其中 3 条是这种失败形态。
2. **8b 长输出质量退化**：单次输出"700-1050 字中文图片段 + 400-700 词英文 H3 视频段"过长，8b 出现漏段/复读/错格式（如某条 raw 只输出图片段 + 循环复读"参考画面/参考风格"）。

## 修复

### 1. `_extract_two_sections` 重写为行级鲁棒版
兼容全部退化形态：
- 分隔线形态：`===` / `---` / `** **` / 带"图片提示词"/"视频提示词"标题 / 无标题（首个分隔=图片→视频分界）
- 独立行标题：`**视频提示词**`、`视频提示词：` 等直接切换视频状态
- **兜底**：完全无分隔线时，按视频特征关键词（`For the target video` / `integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music` / `**视频提示词**`）在图片段内切断——杜绝视频内容混入图片段

### 2. BUILD_SYSTEM 输出协议强化
明确"分隔线只能写 ===，禁止 --- / **视频提示词** / 横线 / 加粗标题；图片提示词段内绝对禁止出现视频内容字样"。

### 3. 视频段缺失提示
generate 返回时若视频段为空（8b 漏段/复读），message 提示"视频提示词未输出（qwen3:8b 输出退化），请重新生成一次"——不静默交付空视频段。
