# 武术指导 · 角色形象图升级（场景天气协调 + 经典武打姿态）

日期：2026-09-29
状态：已验证

## 用户反馈

1. 角色形象图服装与天气不符、违和
2. 动作很丑
3. 建议参考武打电影经典打戏升级人物图提示词

## 根因

角色形象图提示词 = 人物锚定卡转文本（前端 cardToText）。锚定卡原字段只有 scene（如"晨曦庭院"），**没有时段/天气/光感/氛围**，也没有姿态参考 → 模型自由发挥：服装与天气脱节、动作僵硬站桩。

## 升级（backend/app/api/martial_arts.py + 前端）

### 1. PLAN_SYSTEM（招式编排）
- card 输出格式新增两个字段：`scene_weather`（场景+时段+天气+光感+氛围）、`pose_reference`（武打姿态参考）
- **天气氛围(强制)**：scene_weather 必须写"场景+时段+天气+光感+氛围"（如"晨曦庭院：清晨薄雾、柔和晨光、微风拂动衣袂"）；equipment 服装材质厚度/颜色/配饰必须与天气协调（雪地厚棉衣、雨夜斗笠蓑衣、盛夏轻衫），禁止违和
- **姿态参考(强制)**：pose_reference 写经典武打电影标志性姿态特征（黄飞鸿式沉桥架式/叶问式寸劲短打/截拳道式警戒架式/大鹏展翅起手等），通用描述不写真实角色名

### 2. _card_markdown
- 映射表新增两行：`场景天气氛围`、`武打姿态参考` → 自动进入锚定卡 → 进入角色图提示词与 build_input

### 3. BUILD_SYSTEM 图片提示词规范
- 新增**天气光感(强制)**：每格背景写明场景时段天气光感，服装与天气协调，禁止违和

### 4. 前端角色图 prompt 模板（MartialArts/index.tsx）
- 动作要求升级为："动作参考经典武打电影的标志性姿态（黄飞鸿式沉桥架式/叶问式寸劲短打/截拳道警戒架式/大鹏展翅起手等），起手蓄势动态有张力、不僵硬，肢体线条舒展，衣袂带风"
