# 武术指导 · 锚定卡按角色展开 + 字段细化

日期：2026-09-29
状态：已验证

## 用户反馈

人物锚定卡除了"出场人物"和"角色定义"部分出现了追兵1的信息，下面（顶层字段区）还是只有主角的信息。要求把追兵1的详细信息也加上，同时细化服饰细节、武器细节、人物形象细节。

## 根因

1. **锚定卡顶层字段区只承载主角**：性别/年龄/体型与气质/武术体系/装备服装/武器长短 6 个字段全部来自 card 顶层（8b 默认按主角填），追兵1 的信息只在"角色定义"合并行出现一次，图片提示词组装时对手角色的特征可读性弱。
2. **字段粒度不足**：physique/clothing/weapon 允许笼统词（"古装""魁梧"），没有强制材质、颜色、款式、配饰、刃形、长度等细节。

## 修复

### 锚定卡结构重构（_card_markdown）
- 顶层字段区只保留**全局字段**：呈现风格 / 风格调性 / 场景 / 场景天气氛围 / 场景布置与构图 / 武打姿态参考 / 宫格规格 / 兵器 / 影视参考
- **性别/年龄/体型/服装/武器/武术体系改为每角色独立一行**：`角色①/角色②/角色③…`，每个角色完整展示
- 字段标签带细化要求：体型与气质（形象细节）、装备/服装（材质+颜色+款式+细节装饰）、武器（类型+材质）、武器长短（尺寸+刃形/把柄细节）

### PLAN 输出细化（PLAN_SYSTEM）
- characters[] 字段注释升级：physique = 发型/五官/面形/身高体型/气质；clothing = 材质+颜色+款式+细节装饰（纹样/腰带/护腕/发饰/披风）；weapon = 兵器类型+材质；weapon_length = 尺寸长度+刃形/把柄细节
- 新增「形象细节（强制）」规则：禁止笼统词（古装/帅气/漂亮），各字段必须写足细节

### 前端
- 角色定义卡片 placeholder 细化提示：形象细节（发型/五官/身高/面形）、服装（材质+颜色+款式+配饰）、兵器（类型+材质）
- 角色图生成的 `_card_extract_persona` 同步支持"角色①"行提取

## 使用

- 用户显式填写的角色字段原样入卡（填得越细卡越细）；不填角色时 8b 按 PLAN 新规则自动细化输出
- 想让对手角色细节更丰满：在「角色定义（多角色）」里把体型/服装/武器填详细（参考 placeholder 提示）
