# 武术指导 · 分镜图 16 格校验严格化（拦截 6 宫格）

日期：2026-09-29
状态：已验证（真实生成一次通过 4×4 十六宫格）

## 用户反馈

分镜图还是只生成了六宫格。

## 根因

分镜图链路已改为文生图（Flux2-4B）+ qwen2.5vl 视觉校验重试，但校验判定过松、兜底不可靠：

1. **qwen2.5vl 判定过松**：旧逻辑只做字符串包含判断（`"4×4" in ans or "十六宫格" in ans`）——小模型（3B）输出带"4×4"字样的幻觉时 6 格图会被误判通过；
2. **校验异常直接放行**：`except Exception: return True`——2.5vl 调用失败/超时直接算通过，6 格图直接交付；
3. **重试仅 3 次且 seed 固定**：每次用相同 seed 生成，同样式图重复出现，无效重试。

## 修复

### 严格计数校验（_storyboard_is_16grid 重写 + _parse_grid_answer）
- 新增 `_parse_grid_answer`：解析回答为（行, 列, 总格数），支持"4行4列16格 / 4x4 / 16格"等形态
- **只认"行×列=16 或总格数=16"才通过**；6/8 格、"无法判断"一律判失败
- **校验异常/超时 → 判失败**（不再放行），由外层重试兜底

### 重试强化（edit-image）
- 重试次数 3 → **5 次**
- **每次换随机 seed**（`seed=random.randint(0, 2**31-1)`），避免同图重复
- **宫格硬约束追加到提示词**（翻译后）：
  - 英文：`RENDER EXACTLY 16 EQUAL-SIZED SQUARE PANELS IN A 4x4 GRID, numbered 01-16... FORBIDDEN: fewer than 16 panels, 6-panel layout, 2x2 collage, big-and-small panel mixing`
  - 中文回退版同语义
- 5 次全失败 → 明确返回失败 + 保留当前图供查看（不再伪装成功）

## 验证

- 真实调用 edit-image（历史 35c8590c，提示词 1499 字）：**一次生成即 4×4 十六宫格**，目检确认 16 个武侠分镜等大排列、编号有序
- 返回 message：`分镜图生成成功（4×4 十六宫格，已校验）`
- py_compile 通过；后端 PID 67476

## 使用

重新点击「分镜图」生成即可；若 5 次重试仍非 16 格会明确报错并展示当前图，不会再把 6 宫格伪装成成功。
