# 武术指导 · 分镜图修复（文生图化 + 16格校验重试）+ 提示词全链路英文化

日期：2026-09-29
状态：已验证（真实生成目检 + 单测）

## 用户反馈

1. 生成的分镜图乱七八糟
2. 文字分镜提示词和视频提示词也采取"前端中文、后端自动转英文"
3. 提示词增加约束：多宫格海报面部清晰

## 根因

- **分镜图"乱七八糟"**：分镜图走图生图（single_image_edit 4B，角色图参考+16格提示词）。实测 Flux2-Klein-4B 图生图会把 16 格压成 6 格乱拼、人物数量漂移、编号乱码——图生图编辑已有图时对"16 格宫格布局"执行能力差。
- **视频提示词英文混排**：BUILD 直接输出英文 H3 模板，用户不可读；文字分镜提示词（中文）直接喂图生图，Flux2 对中文 16 格海报细节执行差。

## 修复（backend/app/api/martial_arts.py）

### 1. 分镜图改文生图链路（edit-image）
- 根因确认：同一 16 格英文提示词，图生图出 6 格乱拼、**文生图出完整 4×4 十六宫格**（双角色全图一致）→ 分镜图改用 `_build_flux2_4b_text2img_workflow`（text2img 4B）
- 角色一致性：新增 `_card_extract_persona(card_md)`，从锚定卡提取人物/场景行 → 拼进提示词开头（替代图生图参考图）

### 2. 16 格视觉校验 + 自动重试
- Flux2-4B 对 16 格精确执行仍随机（16/8/6/14 格）
- `_storyboard_is_16grid(image_url)`：qwen2.5vl:3b 判断"4行4列16格"，非 16 格 → 自动换 seed 重新生成（最多 3 次）
- 实测校验边界：16 格必判通过、6/8 格判失败重试；14 格（2大格+12小格）可能误判通过 → 提示词补"16 格等大、禁止大小格混排"约束降低 14 格出现率
- 校验失败/异常不阻断（宁可信通过，避免无谓等待）

### 3. 提示词全链路"前端中文、后端转英文"
| 环节 | 展示（前端） | 执行（后端） |
|---|---|---|
| 角色形象图 | 中文 | `_translate_image_prompt` → 英文喂 Flux2-4B |
| 文字分镜提示词 | 中文（build 原样） | edit-image 时 `_translate_image_prompt` → 英文 |
| 视频提示词 | **中文**（build 改中文输出） | generate-video 时 `_to_h3_video_prompt` → H3 英文模板 |

- BUILD_SYSTEM 视频段规范：改为中文节拍叙事输出（节拍｜时长｜画面动作｜镜头｜音效情绪），用户可读
- 新增 `_to_h3_video_prompt(zh)`：中文 → H3 英文模板（首帧对齐指令 + integrated_multimodal_description + overall_soundscape + non_diegetic_music），失败回退中文
  - **关键坑**：第一版 system 提示里放了完整模板示例 → 8b 复读模板框架不翻译内容（swordsman/knife 全缺失）；重写 system（只给字段结构+强制翻译实际内容）+ 模板复读特征检测（含 "<style" / "at least one full action sentence" → 回退中文）

### 4. 面部清晰约束
- BUILD_SYSTEM 图片段新增：所有格人物面部清晰可辨、五官端正对称、比例无畸变、武打表情、不被遮挡
- `_GRID_LAYOUT_HINT` 确定性兜底追加面部约束（翻译后英文同样携带）

## 能力边界（如实说明）

Flux2-Klein-4B（qwen3_4b CLIP）对"16 格精确宫格 + 精确人数"执行有随机性（16/14/8/6 格）。已用"文生图+等大约束+校验重试"把最烂的 6 格乱拼挡掉、提升到 14-16 格完整叙事；100% 精确 16 格需更强模型（9B 或更高），与"分镜图用 4B"的显存约定冲突。前端②按钮可反复点击重新生成，直到满意。
