## 一、分镜图只出四宫格（输入 16 宫格）

**根因**：图片提示词规范只要求"16格按招式列表顺序写入"，但 8b 生成时实际没写"4×4 布局"指令（历史 imagePrompt 全部不含"4×4/十六宫格"字样）→ Flux2-Klein 图生图自由拼图成 2×2 四宫格。grid 参数一直是 '16 = 4×4'，不是用户选错。

**修复（backend/app/api/martial_arts.py）**：
1. BUILD_SYSTEM 图片规范新增 **宫格布局(强制)**：4×4 十六宫格、4行×4列、编号 01-16 与招式一一对应、每格独立小画面、格间细边框、禁止 2×2 四宫格
2. **确定性兜底**：generate 返回前，若 imagePrompt 不含"4×4/十六宫格/宫格"任一关键词，强制追加布局指令（不依赖 8b 自觉）

**验证**：真实 generate → imagePrompt len=1148，含"4×4"+"十六宫格"+"宫格" ✅

## 二、多关键帧模式（试点）

**方案**：H3 自带三帧/四帧参考工作流（three_frame_video / four_frame_video，数据库已有 active）→ 从 16 格海报自动裁关键格作多帧约束，视频更稳定。

**关键帧选取**（从 4×4 海报裁格）：
- 三帧：第1格（起点）+ 第8格（中段）+ 第16格（终点）
- 四帧：第1格 + 第6格 + 第11格 + 第16格

**后端**：
- GenerateVideoRequest.mode 扩展：`ref2va / first_last / three_frame / four_frame`
- 工作流映射：three_frame→three_frame_video、four_frame→four_frame_video
- 多帧模式要求 image_is_storyboard=True（必须分镜海报才能裁格）
- 注入：主参考节点137=第1格；keyframe_node_1/2(/3)=中段/终点格（复用 _crop_grid_cell）

**前端**（MartialArts 页面）：
- 视频模式选项加：三关键帧（起点/中段/终点 → 更稳）、四关键帧（起点/1/3/2/3/终点 → 最稳）
- 校验：多帧模式必须先有分镜图

**验证**：
- three_frame：137=第1格、139=第8格、172=第16格 ✅
- four_frame：137=第1格、139=第6格、172=第11格、173=第16格 ✅
- bad mode / 无海报 校验拦截 ✅
